## Mục tiêu dự án
Xây dựng phần mềm **Trợ lý Trí tuệ Nhân tạo Hỗ trợ Thông tin Học vụ** chính thức cho sinh viên **Trường Đại học Thủ Dầu Một (TDMU)** với hệ thống **Advanced RAG** (chống ảo giác 100%, trích dẫn nguồn chuẩn xác tới từng Chương/Điều/Khoản/Trang, xử lý bảng biểu quy chế đào tạo tín chỉ, chuẩn đầu ra Ngoại ngữ/Tin học và điều kiện học bổng TDMU) cùng các tính năng chuyên sâu như xuất file biểu mẫu tự động, phân tích bảng điểm cá nhân.

## Công nghệ sử dụng
- **Backend:** Python, FastAPI, LangChain, LlamaIndex
- **AI Models:** OpenAI GPT-4o-mini, Text-Embedding-3
- **Database:** Qdrant (Hybrid Search: Dense + Sparse BM25), PostgreSQL (Relational DB)
- **Frontend:** Next.js (React), TailwindCSS (Nhận diện thương hiệu TDMU `#0054A6`)
